# Token-Sus
# Sistema de Token para o SUS

Projeto em Java para gerenciamento de tokens (senhas) de atendimento do SUS.

## Tecnologias
- Java
- Maven (se usar)
- JavaFX ou Swing (se tiver interface)
- PostgreSQL/MySQL (se usar banco)

## Funcionalidades
- Emitir token
- Chamar próximo token
- Painel de atendimento
- Histórico de chamadas

## Como executar
1. Clone o repositório
2. Abra em uma IDE (IntelliJ IDEA, Eclipse ou NetBeans)
3. Execute a classe `Main`
